# Data Structures and Algorithms in Java

A structured collection of **Data Structures and Algorithms (DSA) problems solved using Java**, covering fundamental programming concepts, problem-solving patterns, and coding interview questions.

I've solved these DSA problems in Java as part of my learning journey. I'm always looking to improve, so any suggestions or feedback are welcome! 😊

This repository is organized by topic to make practice, revision, and interview preparation easier.

- Find the maximum and minimum elements

### 3. Dynamic Programming

Learn to solve optimization and counting problems by breaking them into smaller subproblems and reusing previously computed results.

**Approaches covered:**

- **Recursion:** Solve problems by reducing them to smaller instances.
- **Memoization (Top-Down):** Use recursion and caching to avoid repeated calculations.
- **Tabulation (Bottom-Up):** Build solutions iteratively using a DP table.
- **Space Optimization:** Reduce auxiliary space where applicable.

**Problems included:**

- Climbing Stairs
- Fibonacci Series
- Frog Jump
- Frog Jump with K Distance
- House Robber
- House Robber II
- 0/1 Knapsack Problem

📂 [Explore Dynamic Programming Questions](./Dynamic%20Programming%20Questions/)
